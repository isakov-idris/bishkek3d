# BISHKEK 3D — цифровой двойник Бишкека

Интерактивная 3D-карта центра Бишкека в браузере: реальные здания, рельеф, спутник, поиск, маршруты, «видео»-туры и прогулка от первого лица.

**Сайт:** https://isakov-idris.github.io/bishkek3d/

## Что умеет
- **Живой город:** солнце по реальному времени Бишкека, физическое небо, фасады по типу здания (панель, кирпич, стекло, классика, частный дом со скатной крышей — стилизация), тополя и карагачи с ветром, машины на улицах, облака.
- **3D-город:** ~15,8 тыс. реальных зданий (контуры из OpenStreetMap), дороги, парки, вода, деревья, фонари; день/ночь со светящимися окнами.
- **Рельеф:** Copernicus DEM GLO-30 — город стоит на настоящем склоне, на юге хребет Кыргызского Ала-Тоо.
- **Спутник:** подложка Sentinel-2 cloudless 2016 (~10 м/пикс), переключатель «Схема / Спутник».
- **Паспорт здания:** адрес, этажность, высота и её **статус** (из источника / расчётная), крыша, материал, высота над морем, координаты, OSM ID, дата данных.
- **Поиск:** места (~3 тыс.), адреса (~12 тыс.), улицы, категории (кафе, аптеки…).
- **Маршруты:** пешком и на машине (A* по дорожной сети OSM, односторонки), подсказки, голос.
- **Видео-режим:** тур по городу и облёт маршрута с паузой, перемоткой, главами и голосом.
- **Прогулка:** вид с высоты 1,7 м, джойстик или WASD; **«Войти в здание»** — демо-комната на этаже с видом на реальный город, можно загрузить свою модель `.glb`.

## Структура
| Путь | Что это |
|---|---|
| `index.html` | интерфейс |
| `js/app.js` | «режиссёр»: камера, свет, UI, связка модулей |
| `js/city.js` | 3D-геометрия города |
| `js/terrain.js` | рельеф и подложки, функция `elev(x, z)` |
| `js/route.js` | маршруты (граф дорог + A*) |
| `js/search.js` | поиск |
| `js/player.js` | видео-режим и голос |
| `js/walk.js` | прогулка и интерьер |
| `js/atmosphere.js` | небо и солнце по реальному времени Бишкека, отражения |
| `js/life.js` | тополя и карагачи с ветром, машины, облака |
| `js/data.js` | достопримечательности, координаты |
| `data/*.json, *.jpg` | подготовленные данные |
| `tools/process.py` | OSM → `city.json`, `search.json` |
| `tools/terrain.py` | DEM + спутник → `terrain.json`, `sat_*.jpg` |
| `docs/audit-tz.md` | аудит по ТЗ и план |

Система координат: метры от площади Ала-Тоо (42.8762, 74.6038), x — восток, z — юг; высоты — относительно площади (752,9 м н. у. м.).

## Запуск локально
```bash
python3 -m http.server 8000   # затем http://localhost:8000
```

## Обновление данных
1. Скачать OSM по кусочкам через Overpass (зеркало `maps.mail.ru/osm/tools/overpass/api/interpreter`) в `osm/t*.json` и `osm_poi/p*.json`.
2. `python3 tools/process.py` → `data/city.json`, `data/search.json`.
3. `python3 tools/terrain.py` → `data/terrain.json`, `data/sat_city.jpg`, `data/sat_region.jpg`.
