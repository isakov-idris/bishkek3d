# BISHKEK 3D — аудит по ТЗ и план интеграции
_Обновлено 19.11.2026_

## Стек и архитектура
Чистый JavaScript (ES-модули) + Three.js 0.170 (WebGL), без сборщика и бэкенда. Данные — статичные файлы в `data/`, подготавливаются Python-скриптами в `tools/`. Хостинг — GitHub Pages (HTTPS) + копия в артефакте claude.ai.
Координаты: метры от площади Ала-Тоо (42.8762, 74.6038), x — восток, z — юг; высоты относительно площади (752,9 м).

| Требование | Статус | Комментарий |

| 3D City: здания, дороги, парки, вода, деревья | ✅ | OSM, ~15,8 тыс. зданий (центр) |

| Рельеф Copernicus DEM GLO-30 | ✅ | город на реальном склоне + горы Ала-Тоо |
| Satellite mode | ✅ | Sentinel-2 cloudless 2016 (CC BY 4.0), ~10 м/пикс |
| Паспорт здания: ID, координаты, высота + статус, крыша, материал, источник, дата | ✅ | статусы: «из источника» / «расчётная» / «расчётная (оценка)» |
| Поиск адресов, зданий, организаций | ✅ | локальный |
| Маршруты авто/пешком, время, голос | ✅ | A* по OSM, односторонки |
| First Person (1,7 м, WASD, джойстик) | ✅ | режим «Прогулка», столкновения со зданиями |
| Вход в здание (по видео-референсу) | ✅ демо | интерьер помечен как демо; можно загрузить свой .glb |
| GPS / Follow Me | ⏳ следующий этап | работает только на своём хостинге (GitHub Pages) |
| Офлайн (PWA, районы) | ⏳ следующий этап | service worker — только на своём хостинге |
| Street View 360 (Mapillary) | ⏳ нужен токен | бесплатный client token Mapillary |
| Весь Бишкек + пригороды, LOD | ⏳ | докачка OSM по кусочкам, подгрузка по тайлам |
| Microsoft Footprints / Overture | ❌ | хранилища недоступны из среды сборки |
| Google Open Buildings | ⚠️ | покрытие Центральной Азии не подтверждено |
| CesiumJS | ➖ | не нужен: текущий движок справляется (п. 6 ТЗ) |

## Риски
1. Производительность на слабых телефонах — есть переключатели «Деревья» и «Тени»; далее LOD.
2. 81 % высот расчётные — помечены честно; нужны уточнения этажности.
3. Зеркало Overpass перегружено — загрузка кусочками с повторами.
